Ejercicio 2: Polinomio (x+1)^n y Pascal con Memoria Dinámica

Asignación Dinámica en Heap y Desglose Paso a Paso de f(x)

Gestión Estricta de Memoria en C

  • • Asignación Dinámica en Heap: Cada nivel del triángulo se reserva con malloc((i+1) * sizeof(BigInt)).
  • • Construcción Aditiva:
    C(n, k) = C(n-1, k-1) + C(n-1, k)
  • • Liberación Inmediata: Se invoca free(fila_actual) antes de pasar a la siguiente iteración, garantizando cero fugas de memoria (Memory Leaks).

Evaluación Paso a Paso (n = 4, x = 2.0)

(x+1)⁴ = x⁴ + 4x³ + 6x² + 4x + 1

k = 4 | c=1 | x⁴=16.0 | Término = 16.0 k = 3 | c=4 | x³=8.0 | Término = 32.0 k = 2 | c=6 | x²=4.0 | Término = 24.0 k = 1 | c=4 | x¹=2.0 | Término = 8.0 k = 0 | c=1 | x⁰=1.0 | Término = 1.0 ----------------------------------------- Suma acumulada : 81.0 Verificación (2+1)⁴ = 3⁴ = 81.0 (Exacto)

Ejercicio 2: El Reto de n = 100 y Números de 29 Dígitos

Resolución de Desbordamiento de Enteros con BigInt en C

Desbordamiento de 64 Bits

En lenguaje C, un entero de 64 bits (unsigned long long) solo puede almacenar valores hasta 1.84 × 10¹⁹ (19 dígitos), desbordando fatalmente para n ≥ 68.
Para n = 100, el coeficiente central C(100, 50) posee 29 dígitos decimales:
C(100, 50) = 100.891.344.545.564.193.334.812.497.256
Implementamos una estructura BigInt dinámica en C con suma posicional con acarreo, garantizando exactitud matemática absoluta.

Lenguaje Tiempo Fila n = 100 Gestión de Memoria Precisión
Lenguaje C (BigInt) 184.431 microsegundos malloc/free manual por fila Exacta (29 dígitos)
Python 3.12 194.370 microsegundos Listas dinámicas nativas Exacta (Bignum nativo)
