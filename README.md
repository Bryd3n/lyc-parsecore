## Políticas y Estándares de Trabajo
1. **Control de Versiones:** Todos los integrantes colaboran activamente mediante `commits` y `pull requests` verificables.
2. **Defensas Audiovisuales:** Cada estudiante dispone de su respectivo archivo `video_defensa.txt` con el enlace público a Google Drive del video demostrativo individual (máximo 5 min, formato horizontal).
3. **Calidad y Rendimiento:** Implementaciones en C y Python con medición de rendimiento y análisis de complejidad.
